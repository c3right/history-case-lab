# Templates

Reusable project templates:

- [Decision Atom research template](./decision-atom.md)
- [Qualification Sprint template](./qualification-sprint.md)
- [Case Packet template](./case-packet.md)
- [Closed-book Case Packet test template](./closed-book-test.md)
- [Source record template](./source-record.md)

Use the templates together with the active rules in `../AGENTS.md` and methodology under `../docs/`.

Templates are implementation aids, not independent standards. If a template conflicts with the current schema or scoring rubric, the current versioned methodology document wins and the template should be updated.
