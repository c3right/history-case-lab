# Archive

This directory is for materials that are intentionally frozen, superseded or retained only for provenance.

Rules:

- Do not treat `archive/` as an active source of truth.
- Active methodology belongs in `docs/`.
- Active case work belongs in `cases/`.
- When archiving a document, leave a pointer from its former active location or record the move in the roadmap / revision log.
- Do not put the old `notepad` repository behind this archive as a runtime dependency; migrated material needed by the project must exist locally in this repository.
