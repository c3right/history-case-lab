# World-history reading framework — local context stub

This project originally grew alongside a separate macro world-history reading framework. The Decision Atom schema refers to that framework only to explain the relationship between two reading tracks:

- **Macro history**: build the map — structures, institutions, long-run change.
- **History Case Lab**: enter the cockpit — decisions under uncertainty and limited information.

The macro framework is **not required** to use, develop, test, or extend `history-case-lab`.

For this repository, the operative rule is simply:

> **先用宏观史建立地图，再用微观案例进入驾驶舱；先在迷雾里做人，再走出迷雾复盘。**

If the full macro framework is ever needed here, migrate it explicitly into this repository rather than depending on another repository at runtime.
