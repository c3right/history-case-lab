# China-history reading framework — local context stub

This project originally grew alongside a separate macro China-history reading framework. The Decision Atom schema refers to that framework only to explain the relationship between structural history and micro-level life simulation.

For this repository, the important distinction is:

- **Macro China history**: institutions, fiscal structures, frontier relations, social organization, ideas, demography and long-run change.
- **History Case Lab**: how concrete people chose under uncertainty, incomplete information, role constraints and path dependence.

The macro China-history framework is **not required** to operate this repository.

If the full framework is later needed for a particular case, migrate the relevant context into this repository rather than depending on another repository at runtime.
