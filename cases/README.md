# Case workspaces

Each serious case gets its own workspace once it is qualified or intentionally selected for deeper research.

Recommended layout:

```text
cases/<case-id>/
├── README.md       # status, actor, core question, freeze, next step
├── research/       # Decision Atom record, evidence map, qualification notes
├── packet/         # reader packet, reveal, prototype versions
├── sources/        # source map, links, bibliographic notes
└── tests/          # closed-book reading tests and feedback
```
