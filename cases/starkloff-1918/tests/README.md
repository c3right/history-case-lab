# Starkloff closed-book tests

Use [the closed-book test template](../../../templates/closed-book-test.md).

The first test should use `Case Packet Prototype v0.1` without any extra briefing. Record:

- reader prior familiarity;
- decision and confidence at Freeze;
- whether at least two options felt reasonable;
- answer leakage;
- background load;
- authority comprehension;
- modern/COVID analogy contamination;
- outcome bias after Reveal;
- concrete revision recommendations.

Suggested filename:

`test-001-YYYY-MM-DD.md`
