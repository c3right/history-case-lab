# Structured data

This directory stores lightweight structured registries used by the project.

Current files:

- `candidates.yaml` — current case candidate registry and build status.

Rules:

- Structured data supplements, but does not replace, narrative research notes.
- Do not store copyrighted source texts here.
- Prefer stable case IDs over person names alone.
- When status materially changes, update both the relevant case README / research note and this registry.
